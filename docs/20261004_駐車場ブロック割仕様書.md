# 駐車場ブロック割 自動作成ソフト 仕様書

作成日: 2026-10-04

## 1. 目的

地図上で範囲を指定すると、駐車マスと車路の配置（ブロック割）を自動で作成する。
業務の実施設計で、CAD図面の下敷きとしてそのまま使える寸法精度を目標とする。

## 2. 全体仕様

| 項目 | 内容 |
|---|---|
| 対象車種 | 普通乗用車、車いす使用者用、大型車（バス・トラック）、二輪車・自転車 |
| 寸法基準 | 駐車場設計・施工指針（日本道路協会）を初期値とし、画面で変更できる |
| 範囲指定 | 地図上で多角形をクリックして描く。頂点はドラッグで修正できる |
| 駐車方式 | 直角（90°）・斜め（60°、45°）・縦列を試算し、台数の多い順に案を一覧表示。任意の案を採用できる |
| 出入口・障害物 | 出入口は境界線上に置く。障害物（建物・植栽・電柱など）は多角形で除外する。車路は出入口につながるように配置する |
| 車種の割り振り | 範囲内をエリア（普通車・大型車・二輪）に分け、エリアごとに自動割付する |
| 出力 | DXF（平面直角座標、レイヤ分け）、PDF図面、台数集計表（Excel・CSV）、プロジェクト保存（再編集用） |
| 動作環境 | Webアプリ。Mac・iPad・Windows のブラウザで使う |
| 背景地図 | Google 航空写真・地図、国土地理院の写真・標準地図を切り替える |
| 位置精度 | 航空写真のずれは避けられないため、測量図との最終合わせは CAD で行う |
| 手動編集 | マスの削除・追加、列単位の移動 |
| Google Maps APIキー | 画面で入力する。キーがない間は地理院地図だけで動く |
| 利用者・公開 | 本人と社内数名。GitHub Pages で公開し、データはサーバーに残さない |

## 3. 段階計画

| 段階 | 内容 | 状況 |
|---|---|---|
| 第1段階 | 多角形指定、出入口・障害物、普通車と車いす用の自動割付（角度比較）、DXF出力 | 完了 |
| 第2段階 | エリア分割と大型車・二輪車、台数集計表、プロジェクトのファイル保存 | 完了（5章） |
| 第3段階 | マスの手動編集、PDF図面 | 作成済み（6章） |

## 4. 第1段階の詳細

### 4.1 画面の流れ

1. 地図: 住所（または「緯度,経度」）で移動、背景と平面直角座標系（初期値 IX 系）を選ぶ
2. 敷地: 「範囲を描く」で敷地の角を順にクリックし、最初の点か「確定」で閉じる。「障害物を追加」「出入口を追加」も同様
3. 寸法条件: マス寸法、角度別の車路幅、幹線車路幅、車いす用台数などを入力する
4. 自動割付: 実行すると全案を試算し、台数順に一覧表示する。行をクリックすると地図に表示する
5. 出力: 選んだ案を DXF で保存する（ファイル名 `YYYYMMDD_parking_block.dxf`）

入力した敷地と条件はブラウザ内に自動保存し、次に開いたときに復元する。

### 4.2 寸法の初期値

| 項目 | 初期値 | 根拠・備考 |
|---|---|---|
| 普通乗用車マス | 幅 2.5m × 奥行 6.0m | 駐車場設計・施工指針 |
| 車いす使用者用マス | 幅 3.5m | 建築物移動等円滑化基準 |
| 車路幅 直角 | 6.0m | 対面通行を想定 |
| 車路幅 60° | 4.5m | 一方通行を想定 |
| 車路幅 45° | 3.5m | 一方通行を想定 |
| 車路幅 縦列 | 3.5m | 一方通行を想定 |
| 縦列マス | 長さ 7.0m × 幅 2.5m | |
| 幹線車路 | 6.0m | 出入口から通す対面通行の車路 |
| 出入口幅 | 6.0m | |
| 境界・障害物からの離れ | 0m | |
| 行き止まり車路をなくす | 有効 | 画面のチェックで切替 |
| 余白にマスを追加 | 有効 | 画面のチェックで切替 |

角度別の車路幅と縦列マスは、案件ごとに指針の表や発注者基準と照合して修正すること。

### 4.3 割付の方法

1. 敷地から障害物を差し引いて、配置できる範囲を求める
2. 車路の向きの候補を、敷地の辺の向き（長い辺から最大6方向）とその直角方向とする
3. 出入口から敷地の内側へ、車路と直交する幹線車路を通す。出入口が車路と平行な辺にあれば敷地を横断し、直交する辺にあれば境界沿いに通る
4. 「マス列＋車路＋マス列」の帯を平行に並べ、帯の位置を少しずつずらして台数が最大になる位置を探す
5. 行き止まり車路をなくす設定のときは、隣り合う車路の端どうしを連絡車路（幅はその方式の車路幅）でつなぐ。幹線車路に接している端には作らない。境界が斜めの場合は端から最大3m内側へずらして置ける位置を探す
6. 各列では端からマスを詰め、範囲内に完全に収まり、前面の車路も範囲内にあるマスだけを残す。連絡車路と重なるマスは置かない
7. 幹線車路に、直接または連絡車路を通じてつながらない車路に面するマスは除く
8. 斜め駐車・縦列では車路を一方通行とし、隣り合う車路で通行方向を交互にする。斜めのマスは面する車路の通行方向に傾ける。連絡車路と合わせて蛇行状に一周できる流れになる
9. 車いす使用者用マス（幅3.5m×奥行6.0m の長方形）は、出入口に最も近いマスを起点に配置する。斜め駐車の案でも同じ長方形を列の中に置く（縦列の案は奥行が足りないため置かない）
10. 余白にマスを追加する設定のときは、幹線車路・連絡車路の両脇に直角マス（通路幅が直角駐車の車路幅以上の場合）と縦列マスを、車路の両脇に縦列マスを、空いている所へ詰める。追加した台数は一覧の「余白+N」で示す
11. 出入口がある場合に行き止まりの車路が残ったときは、その数を警告に出す

斜め駐車のマスは、車両の長方形（幅×奥行）が収まる平行四辺形とする。
車路方向のピッチ = 幅 ÷ sinθ、奥行 = 奥行×sinθ + 幅×cosθ。

### 4.4 DXF の内容

- 形式: R12（AC1009）。多くの CAD で読める
- 座標: 平面直角座標（JGD2011, m）。作図 X = 東方向（測量 Y）、作図 Y = 北方向（測量 X）
- レイヤ

| レイヤ | 内容 | 色 |
|---|---|---|
| BOUNDARY | 敷地境界 | 赤 |
| OBSTACLE | 障害物 | 灰 |
| STALL | 駐車マス | 白 |
| STALL_HC | 車いす使用者用マス | 青 |
| AISLE | 車路 | 緑 |
| TRUNK | 幹線車路 | 水色 |
| ENTRANCE | 出入口 | 紫 |
| ARROW | 一方通行の矢印 | 橙 |
| TEXT | マス番号・台数 | 黄 |

文字は互換性のため英数字のみ（車いす用マスは `HC` 付きの番号）。

### 4.5 第1段階の制約

- 連絡車路を置けない端（隣に車路がない、障害物がある等）は行き止まりのまま残り、転回スペースは確保しない
- 連絡車路・幹線車路の上には通行方向の矢印を描かない
- 縦列駐車の案では車いす用マスを自動配置しない
- 敷地が数ヘクタール規模になると計算に10秒程度かかる

## 5. 第2段階の詳細

### 5.1 エリア分割

- 「2. 敷地」の「エリアを追加」で、種類（大型車・バイク・自転車）を選んでから敷地内に多角形を描く。描かなかった残りは普通車エリアになる
- エリアは敷地の外にはみ出した部分を使わない。エリア同士が重なる場合は先に描いたエリアを優先する
- 各エリアは、その車種の寸法で第1段階と同じ方法（角度比較・周回車路・余白追加）で割付する

### 5.2 エリアの接続口

- 特別エリア（大型車・バイク・自転車）には、車路の入口となる「接続口」を自動で決める
  - 敷地の出入口がエリアの輪郭上にあれば、それを接続口にする
  - なければ、敷地境界に沿っていない辺（普通車エリアと接する辺）の上で、最寄りの出入口に最も近い点を接続口にする（辺の端から少し内側に寄せる）
- 特別エリアは接続口から、普通車エリアは敷地の出入口と各接続口から、幹線車路を通す
- 敷地の出入口から接続口までの経路が普通車エリアの車路でつながるかは自動では確かめない。図面で確認すること

### 5.3 車種別の寸法の初期値

| 項目 | 大型車 | バイク | 自転車 |
|---|---|---|---|
| マス（幅×奥行） | 3.3m × 13.0m | 1.0m × 2.3m | 0.6m × 1.9m |
| 車路幅 直角 | 13.0m | 2.5m | 1.5m |
| 車路幅 60° / 45° | 10.0m / 8.0m | 2.0m / 2.0m | 1.5m / 1.5m |
| 幹線車路幅 | 8.0m | 3.0m | 2.0m |
| 試算する方式 | 直角・60°・45° | 直角 | 直角 |

マス寸法は駐車場設計・施工指針の値（自転車を除く）。車路幅・幹線車路幅は一般的な目安の値なので、案件の基準と照合して「3. 寸法条件」の車種タブで修正する。

### 5.4 結果の表示

- 合計台数（普通車・車いす使用者用・大型車・バイク・自転車）を上に表示する
- エリアごとに案の一覧を表示し、行をクリックするとそのエリアだけ案を切り替える。初期状態は各エリアの台数最大案

### 5.5 Excel 集計表

ファイル名 `YYYYMMDD_案件名_count.xlsx`。

| シート | 内容 |
|---|---|
| 集計 | 案件名・作成日・座標系、車種別の台数と区画外周延長、エリア別の面積・駐車方式・車路方向・台数 |
| マス一覧 | 番号・種類・エリア・中心座標（平面直角座標 X=東 / Y=北）・幅・長さ |

区画外周延長はマスの外周の長さの合計で、隣り合うマスが共有する辺は1回だけ数える。区画線の塗装数量とは一致しないので、数量計算には参考値として使う。

### 5.6 案件ファイル

- 「案件を保存」で `YYYYMMDD_案件名.parking.json` を保存、「案件を開く」で読み込む
- 中身は敷地・障害物・出入口・エリア、車種別の寸法条件、座標系、地図の表示位置、背景。割付結果は含まない（開いた後に「自動割付を実行」する）
- ブラウザ内の自動保存も同じ形式。第1段階の自動保存データもそのまま読める

### 5.7 DXF の追加レイヤ

| レイヤ | 内容 | 色 |
|---|---|---|
| STALL_LARGE | 大型車マス | 赤 |
| STALL_BIKE | バイクマス | 水色 |
| STALL_BICYCLE | 自転車マス | 緑 |
| AREA | 特別エリアの境界 | 薄灰 |

マス番号は種類ごとの通し番号で、普通車は数字のみ、車いす用 `HC`、大型車 `L`、バイク `M`、自転車 `C` を頭につける。ファイル名は `YYYYMMDD_案件名_block.dxf`。

## 6. 第3段階の詳細

### 6.1 マスの手直し

「4. 自動割付」の「マスを手直しする」で手直しを始め、「手直しを終える」で終わる。

| 操作 | 方法 |
|---|---|
| 選ぶ | マスをクリック（もう一度クリックで外す。複数選べる） |
| 列ごと選ぶ | 1台選んで「列ごと選ぶ」。前面の辺が同一直線上（向き1°以内・ずれ5cm以内）で、奥の向きと奥行が同じマスを列とみなす |
| 削除 | 選んで「選んだマスを削除」 |
| 追加 | 割付したエリアの空いている所をクリック。近くの普通マスを手本にし、その列の方向でクリック位置に最も近いマス何個分か隣に同じ形で置く。指した位置が他のマスで埋まっていれば同じ向きに最大3つ先まで試す。エリアからはみ出す・車路と重なる位置には置かない |
| 移動 | 選んで「◀ 列方向」「列方向 ▶」「▲ 奥へ」「▼ 車路側へ」。刻みは 0.1 / 0.5 / 1.0 m。移動の結果、他のマス・車路と重なる、またはエリアからはみ出すマスは赤で示す（移動自体は行う） |
| 元に戻す | 直前の操作を取り消す（50手まで） |

- 手直しした割付には合計台数の横に「※手直しあり」と表示する
- 手直しの後で、割付のやり直し・別の案への切替をするときは確認を出す。敷地や寸法条件を変えたときは手直しした割付を消し、その旨を表示する
- マス番号は DXF・Excel・PDF を出力するたびに並び順で振り直す。エリアごとに、車路方向に直角な位置で列に分け（前面の辺の位置が 0.5m 以上離れたら別の列）、列の順・列の中は車路方向の順に番号を振る。手直しで追加したマスも置いた位置の番号になる

### 6.2 案件ファイル（版2）

- 割付結果（各エリアの採用案、手直しを含む）を案件ファイルとブラウザ内の自動保存に入れる。開くと計算し直さずにそのまま表示する
- 保存するのは採用した案だけなので、開いた後の案の一覧は1行になる。別の案を見たいときは「自動割付を実行」する
- 結果を作ったときと座標系が違う場合は、結果を使わない
- 版1（第2段階）のファイルも読める

### 6.3 PDF 図面

ファイル名 `YYYYMMDD_案件名_plan.pdf`。「5. 保存・出力」で用紙・縮尺・背景を選んで保存する。

| 項目 | 内容 |
|---|---|
| 用紙 | A4・A3・A1（横）。初期値は A3 |
| 縮尺 | 自動: 1/100・1/200・1/250・1/300・1/500・1/600・1/1000・1/1500・1/2000・1/2500 のうち、作図範囲に敷地と全マスが収まる最も大きい縮尺。手動で選ぶこともでき、収まらないときは注意を表示する |
| 図面本体 | 敷地境界、障害物、車種エリアの境界、車路、幹線車路、出入口、一方通行の矢印、マス（車種で色分け）、マス番号（紙の上で文字高さ 0.7mm 未満になるときは省略）。線はベクトル |
| 右欄 | 方位記号（上が座標北）、スケールバー、凡例、駐車台数表、表題欄（件名・図名・縮尺・作成日・座標系） |
| 背景 | 「地理院写真あり」または「線画のみ」。写真は地理院タイル（全国最新写真（シームレス））を取得し、作図範囲の3隅で Web メルカトルから平面直角座標へ位置を合わせて敷く。出典を図面内に記載する。タイルを取得できないときは線画のみで保存し、その旨を表示する |

- Google の航空写真は利用規約上 PDF に埋め込めないため使わない
- 日本語の文字は、日本語フォントを PDF に埋め込むとファイルが数MB 大きくなるため、画像として貼っている（拡大すると文字がややぼやける）。マス番号・数字はベクトルの文字
- 方位は平面直角座標の北（座標北）。真北とのずれ（子午線収差角）は系の原点から離れるほど大きくなるが、駐車場の規模では図面上ほとんど区別できない
