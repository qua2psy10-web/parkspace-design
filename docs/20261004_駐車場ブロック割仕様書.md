# 駐車場ブロック割 自動作成ソフト 仕様書

作成日: 2026-10-04

## 1. 目的

地図上で範囲を指定すると、駐車マスと車路の配置（ブロック割）を自動で作成する。
業務の実施設計で、CAD図面の下敷きとしてそのまま使える寸法精度を目標とする。

## 2. 全体仕様

| 項目 | 内容 |
|---|---|
| 対象車種 | 普通乗用車、車いす使用者用、大型車（バス・トラック）、二輪車・自転車 |
| 寸法基準 | 駐車場設計・施工指針（日本道路協会）を初期値とし、画面で変更できる |
| 範囲指定 | 地図上で多角形をクリックして描く。頂点はドラッグで修正できる |
| 駐車方式 | 直角（90°）・斜め（60°、45°）・縦列を試算し、台数の多い順に案を一覧表示。任意の案を採用できる |
| 出入口・障害物 | 出入口は境界線上に置く。障害物（建物・植栽・電柱など）は多角形で除外する。車路は出入口につながるように配置する |
| 車種の割り振り | 範囲内をエリア（普通車・大型車・二輪）に分け、エリアごとに自動割付する |
| 出力 | DXF（平面直角座標、レイヤ分け）、PDF図面、台数集計表（Excel・CSV）、プロジェクト保存（再編集用） |
| 動作環境 | Webアプリ。Mac・iPad・Windows のブラウザで使う |
| 背景地図 | Google 航空写真・地図、国土地理院の写真・標準地図を切り替える |
| 位置精度 | 航空写真のずれは避けられないため、測量図との最終合わせは CAD で行う |
| 手動編集 | マスの削除・追加、列単位の移動 |
| Google Maps APIキー | 画面で入力する。キーがない間は地理院地図だけで動く |
| 利用者・公開 | 本人と社内数名。GitHub Pages で公開し、データはサーバーに残さない |

## 3. 段階計画

| 段階 | 内容 | 状況 |
|---|---|---|
| 第1段階 | 多角形指定、出入口・障害物、普通車と車いす用の自動割付（角度比較）、DXF出力 | 今回作成 |
| 第2段階 | エリア分割と大型車・二輪車、台数集計表、プロジェクトのファイル保存 | 未着手 |
| 第3段階 | マスの手動編集、PDF図面 | 未着手 |

## 4. 第1段階の詳細

### 4.1 画面の流れ

1. 地図: 住所（または「緯度,経度」）で移動、背景と平面直角座標系（初期値 IX 系）を選ぶ
2. 敷地: 「範囲を描く」で敷地の角を順にクリックし、最初の点か「確定」で閉じる。「障害物を追加」「出入口を追加」も同様
3. 寸法条件: マス寸法、角度別の車路幅、幹線車路幅、車いす用台数などを入力する
4. 自動割付: 実行すると全案を試算し、台数順に一覧表示する。行をクリックすると地図に表示する
5. 出力: 選んだ案を DXF で保存する（ファイル名 `YYYYMMDD_parking_block.dxf`）

入力した敷地と条件はブラウザ内に自動保存し、次に開いたときに復元する。

### 4.2 寸法の初期値

| 項目 | 初期値 | 根拠・備考 |
|---|---|---|
| 普通乗用車マス | 幅 2.5m × 奥行 6.0m | 駐車場設計・施工指針 |
| 車いす使用者用マス | 幅 3.5m | 建築物移動等円滑化基準 |
| 車路幅 直角 | 6.0m | 対面通行を想定 |
| 車路幅 60° | 4.5m | 一方通行を想定 |
| 車路幅 45° | 3.5m | 一方通行を想定 |
| 車路幅 縦列 | 3.5m | 一方通行を想定 |
| 縦列マス | 長さ 7.0m × 幅 2.5m | |
| 幹線車路 | 6.0m | 出入口から通す対面通行の車路 |
| 出入口幅 | 6.0m | |
| 境界・障害物からの離れ | 0m | |
| 行き止まり車路をなくす | 有効 | 画面のチェックで切替 |
| 余白にマスを追加 | 有効 | 画面のチェックで切替 |

角度別の車路幅と縦列マスは、案件ごとに指針の表や発注者基準と照合して修正すること。

### 4.3 割付の方法

1. 敷地から障害物を差し引いて、配置できる範囲を求める
2. 車路の向きの候補を、敷地の辺の向き（長い辺から最大6方向）とその直角方向とする
3. 出入口から敷地の内側へ、車路と直交する幹線車路を通す。出入口が車路と平行な辺にあれば敷地を横断し、直交する辺にあれば境界沿いに通る
4. 「マス列＋車路＋マス列」の帯を平行に並べ、帯の位置を少しずつずらして台数が最大になる位置を探す
5. 行き止まり車路をなくす設定のときは、隣り合う車路の端どうしを連絡車路（幅はその方式の車路幅）でつなぐ。幹線車路に接している端には作らない。境界が斜めの場合は端から最大3m内側へずらして置ける位置を探す
6. 各列では端からマスを詰め、範囲内に完全に収まり、前面の車路も範囲内にあるマスだけを残す。連絡車路と重なるマスは置かない
7. 幹線車路に、直接または連絡車路を通じてつながらない車路に面するマスは除く
8. 斜め駐車・縦列では車路を一方通行とし、隣り合う車路で通行方向を交互にする。斜めのマスは面する車路の通行方向に傾ける。連絡車路と合わせて蛇行状に一周できる流れになる
9. 車いす使用者用マス（幅3.5m×奥行6.0m の長方形）は、出入口に最も近いマスを起点に配置する。斜め駐車の案でも同じ長方形を列の中に置く（縦列の案は奥行が足りないため置かない）
10. 余白にマスを追加する設定のときは、幹線車路・連絡車路の両脇に直角マス（通路幅が直角駐車の車路幅以上の場合）と縦列マスを、車路の両脇に縦列マスを、空いている所へ詰める。追加した台数は一覧の「余白+N」で示す
11. 出入口がある場合に行き止まりの車路が残ったときは、その数を警告に出す

斜め駐車のマスは、車両の長方形（幅×奥行）が収まる平行四辺形とする。
車路方向のピッチ = 幅 ÷ sinθ、奥行 = 奥行×sinθ + 幅×cosθ。

### 4.4 DXF の内容

- 形式: R12（AC1009）。多くの CAD で読める
- 座標: 平面直角座標（JGD2011, m）。作図 X = 東方向（測量 Y）、作図 Y = 北方向（測量 X）
- レイヤ

| レイヤ | 内容 | 色 |
|---|---|---|
| BOUNDARY | 敷地境界 | 赤 |
| OBSTACLE | 障害物 | 灰 |
| STALL | 駐車マス | 白 |
| STALL_HC | 車いす使用者用マス | 青 |
| AISLE | 車路 | 緑 |
| TRUNK | 幹線車路 | 水色 |
| ENTRANCE | 出入口 | 紫 |
| ARROW | 一方通行の矢印 | 橙 |
| TEXT | マス番号・台数 | 黄 |

文字は互換性のため英数字のみ（車いす用マスは `HC` 付きの番号）。

### 4.5 第1段階の制約

- 連絡車路を置けない端（隣に車路がない、障害物がある等）は行き止まりのまま残り、転回スペースは確保しない
- 連絡車路・幹線車路の上には通行方向の矢印を描かない
- 縦列駐車の案では車いす用マスを自動配置しない
- 敷地が数ヘクタール規模になると計算に10秒程度かかる
