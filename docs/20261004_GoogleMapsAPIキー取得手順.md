# Google Maps APIキー 取得手順

作成日: 2026-10-04

このアプリで Google の航空写真を使うための APIキーの取り方です。
キーがなくても国土地理院の地図で使えます。

## 費用について

- 利用には Google Cloud への請求先（クレジットカード）の登録が必要です
- 地図の読み込み（Dynamic Maps）には毎月の無料枠があり、数名で業務に使う程度なら通常は無料枠内に収まります
- 料金体系は変わることがあるため、最新の内容は公式の料金ページで確認してください
  https://developers.google.com/maps/billing-and-pricing/pricing
- 想定外の請求を防ぐため、手順5の「予算アラート」と「割り当て上限」の設定をおすすめします

## 手順

### 1. Google Cloud にログインしてプロジェクトを作る

1. https://console.cloud.google.com/ を開き、Google アカウントでログイン
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」
3. 名前を入れて（例: parkspace-design）作成

### 2. 請求先アカウントを設定する

1. 左上のメニュー →「お支払い」
2. 画面の案内に従って請求先アカウントを作り、プロジェクトにリンクする

### 3. Maps JavaScript API を有効にする

1. メニュー →「APIとサービス」→「ライブラリ」
2. 「Maps JavaScript API」を検索して「有効にする」

### 4. APIキーを作り、使える場所を制限する

1. メニュー →「APIとサービス」→「認証情報」
2. 「認証情報を作成」→「APIキー」
3. 作成されたキーの「キーを編集」を開き、次のとおり設定して保存
   - アプリケーションの制限: **ウェブサイト**
     - 公開先のアドレスを追加: `https://qua2psy10-web.github.io/parkspace-design/*`
     - 手元で試す場合は `http://localhost:5173/*` も追加
   - API の制限: **キーを制限** →「Maps JavaScript API」だけを選ぶ

制限をかけておくと、キーが他人に知られても別のサイトでは使えません。

### 5. 予算アラートと上限を設定する（推奨）

1. メニュー →「お支払い」→「予算とアラート」→ 予算を作成（例: 月 1,000円、50%・90%・100% で通知）
2. メニュー →「APIとサービス」→「Maps JavaScript API」→「割り当て」で 1日あたりの上限を設定（例: 1日 300 回）

### 6. アプリに入力する

1. アプリの「1. 地図」→「Google Maps APIキー」を開く
2. キーを貼り付けて「保存」
3. 画面が再読み込みされ、背景に「Google 航空写真」が選べるようになります

キーはそのブラウザの中にだけ保存され、他の人やサーバーには送られません（Google への地図読み込み時を除く）。
社内の別の人が使う場合は、同じキーを各自のブラウザで入力してください。
